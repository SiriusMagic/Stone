# Stone: reglas para agentes

- Lee `ARQUITECTURA.md`, luego `android-native/AGENTS.md` y `android-native/MAP.md`; abre solo lo que necesites.
- Pruebas: `cd android-native && ./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assemblePreview`
  (debe pasar todo). Nunca desactives ni saltes una prueba. Lint sin avisos nuevos.
- Cada versión: usa la habilidad `stone-apk-release`.
- La versión web antigua ya no existe en el repo (ver `README.md`); no la vuelvas a traer.
